# 광고성과 데이터 갱신

`유입엑셀추가`에서 파일을 선택하고 **변경 내역 확인**을 누르거나, **데이터 갱신**을 누르면 날짜별 변경 전·후 값을 확인하는 팝업이 열린다. **확인 후 업데이트**를 눌러야 지표와 원본 파일을 저장한다. 취소하면 저장하지 않는다.

- 신청 목록의 그로스임팩트 구글·메타 유입은 서울 기준 오늘 이전의 모든 날짜를 집계한다. 어제만 갱신하던 제한을 제거했다.
- 신청 목록은 전체 신청 내역을 담은 파일로 취급한다. 과거 건수의 증가·감소, 매체 변경, 채널 삭제, 신청이 없는 날짜의 0건도 비교한다. 일부 기간만 담긴 파일을 올리면 다른 날짜의 값이 감소할 수 있으므로 팝업에서 확인한다.
- 누적 비즈업 DB는 각 날짜까지의 신청 건수를 다시 계산한다. 톡방누적인원 수동 입력값은 유지한다.
- `데이터 갱신`은 Google 원본 시트와 저장된 유입 파일을 다시 읽어 같은 확인 절차를 거친다. 일자별 묶음 형식은 파일에 기록된 일자별 집계값을 사용한다.
- 팝업은 변경된 원본 지표, 유입·오가닉, 누적 DB, 합계와 단가를 표시하고 50개 항목씩 페이지를 나눈다. 변경이 없으면 별도로 안내한다.
- 확인 도중 저장 버전·파일·Google 원본 내용이 바뀌면 새로운 내역으로 다시 확인받는다. 확인 후 저장할 때도 기존 DB 버전 검사를 적용한다.

API의 POST는 기본적으로 미리보기 응답만 반환한다. 저장하려면 `action: confirm`, 미리보기에서 받은 `version`과 `fingerprint`를 다시 보내야 한다. 파일 업로드는 동일 파일도 함께 보낸다. 새 확인이 필요한 경우 HTTP 409와 새 `preview`를 반환한다.

검증: `src/lib/ad-performance/sheet-update.test.ts`, `scripts/verify-ad-performance-update.cjs`. 브라우저 검증은 실제 라우트·파일 파서·저장 함수를 사용하고 DB/Storage 전송만 메모리로 대체한다. 운영 데이터는 수정하지 않는다.
