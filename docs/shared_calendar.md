# 공용캘린더

- 메인 대시보드의 **공용캘린더** 카드 → `/calendar`.
- 공용 워크스페이스의 활성 로그인 사용자는 일정을 함께 조회·등록·수정·삭제한다. 익명 사용자에게 공개하지 않는다.
- 일정 필드: 제목, 날짜, 회의 종류, 시작시간/시간 미정, 소요시간, 장소, 참여자, 메모. 한국시간 기준이다.
- 장소는 **온라인**, **장소미정**, **입력** 중 선택한다. 입력을 선택하면 별도 장소 입력란이 활성화된다. 장소는 달력의 일정 목록, 강의 연결 일정, 공유 텍스트에도 표시한다.
- 날짜 버튼 또는 빈 날짜 영역을 더블클릭하면 해당 날짜의 일정 등록창을 연다. 일정은 한 번 클릭하면 날짜를 선택하고, 더블클릭하면 수정창을 연다. 키보드 Enter/Space로도 등록·수정할 수 있다.
- 일정을 다른 날짜로 마우스 드래그하면 날짜만 변경한다. 시작시간·소요시간·참여자·강의 연결은 유지하고, 오래된 버전의 이동 요청은 409로 거부한다.
- 새 일정의 기본 소요시간은 1시간이다. 제목의 `11시`, `오후 2시 반`, `11시 30분`, `14:30` 등을 시작시간에 반영한다. 오전·오후가 없는 1~7시는 오후로 해석하며, 허용 범위/30분 간격 밖의 시간은 자동 반영하지 않는다. 수동 시작시간 선택과 기존 소요시간은 보존한다.
- 참여자는 같은 워크스페이스의 이메일 인증 완료·비활성/차단되지 않은 사용자 중 복수 선택한다. 전체 선택·선택 해제가 가능하며, 0명도 유효하다. 참여자 디렉터리 장애가 일정 저장을 막지 않는다.
- **내가 포함된 항목만 보기**는 기본 꺼짐이다. 켜면 서버에서 확인한 로그인 계정 ID가 참여자에 포함된 공용 일정만 달력과 선택한 날짜 목록에 표시한다. 작성자 여부는 관계없고, 참여자가 없는 일정은 제외한다. 회의 종류 필터와 함께 적용하며, 옵션을 끄면 전체 일정을 다시 표시한다. 강의 웨비나·직원 휴가 연동 항목은 이 참여자 필터와 무관하게 각 표시 체크박스를 따른다. 기존 조회 권한/RLS와 DB 구조는 변경하지 않는다.
- 수정창의 **공유** 버튼은 현재 입력한 제목·한국시간·장소·종류·연결 강의·참여자·메모를 일반 텍스트로 복사한다. 카카오톡 등에 붙여넣을 수 있다. 클립보드 접근이 거부되면 직접 선택·복사할 텍스트를 보여준다. 외부 메시지를 자동 발송하지 않는다.
- 시작시간: 08:00~21:00, 30분 간격. 소요시간: 30분~24시간, 30분 간격. 종료가 다음 날이면 이를 표시한다. 21:00 제한은 시작시간에 적용한다.
- 기본 종류: 강사 줌미팅, 리허설, 웨비나, 주간회의.
- 최고관리자 `/admin`의 **회의 항목 추가** 섹션 또는 워크스페이스 관리자 `/admin/calendar`에서 종류를 추가한다. 중복 이름은 거부한다.
- 강사 줌미팅에는 같은 워크스페이스의 강의를 선택적으로 연결할 수 있다. 다른 종류로 변경하면 강의 연결을 해제한다.
- 강의 상세페이지 하단에 연결된 모든 일정과 메모를 날짜·시간순으로 표시한다. 강의 삭제는 일정 자체를 삭제하지 않고 연결만 해제한다.
- 캘린더는 30초 주기 및 창 포커스 시 다른 사용자의 변경을 새로 조회한다. 편집 중 다른 사용자가 변경한 일정은 저장/삭제 시 409로 거부하여 덮어쓰지 않는다.
- 표시 옵션은 상단 관리 버튼 왼쪽에 배치한다. 날짜 행 높이는 화면 높이에 맞춰 조절하고, 같은 날짜의 많은 일정 및 하단 상세 목록은 내부 스크롤로 모두 확인할 수 있다. 공통 안내 문구는 제거하고, 등록·수정·키보드 조작은 그대로 유지한다.

## 강의 웨비나·직원 휴가 연동

- 강의 상세의 무료 웨비나 일시를 해당 날짜에 자동 표시한다. 한국시간을 사용하고, 날짜만 저장된 자정 값은 시간 미정으로 표시한다. 실제 시작시간만 보여주며, 원본에 없는 소요시간을 임의로 만들지 않는다.
- **강의 웨비나 표시**는 기본 켜짐이며 자동 연동 항목만 숨기거나 표시한다. 수동으로 등록한 회의 종류 ‘웨비나’ 일정은 이 옵션과 별개다. 회의 종류 필터에서는 연동 웨비나도 웨비나 종류에 포함한다.
- **직원 휴가 표시**는 기본 꺼짐이다. 켜면 같은 워크스페이스의 활성 직원에 대해 승인된 종일 휴가·오전 반차·오후 반차를 표시한다. 대기·반려·취소 내역과 비활성·퇴직 직원은 제외한다. 휴가 사유·검토 메모·잔여 일수는 캘린더에서 조회하거나 노출하지 않는다.
- 휴가는 최신 `personnel_access` 확인을 통과한 직원만 조회한다. 서버가 기존 HR 데이터에서 승인된 날짜·구분·이름만 공유용으로 추출하며, 기존 HR 테이블의 개인/관리자 RLS와 쓰기 권한은 변경하지 않는다. 옵션을 끄면 HR 조회 자체를 하지 않는다.
- 연동 일정 제목을 누르면 원래 강의 상세 또는 휴가 관리 화면으로 이동한다. 캘린더에서 연동 항목을 드래그하거나 회의 수정창으로 편집하지 않는다. 원본 일시 변경·휴가 취소 후 새로고침하면 캘린더에도 반영된다.
- 연동 항목은 공용 일정 테이블에 복사하지 않는다. 별도 마이그레이션이 필요하지 않으며, 선택 연동 조회 장애는 다른 일정 조회를 막지 않고 경고를 표시한다.

## 일괄 입력

캘린더 상단 **일괄 입력** → 일정 목록 붙여넣기 → **분석 및 미리보기** → 필요한 항목 확인 → **일정 등록** 순서로 사용한다. 한 번에 최대 100건, 30,000자까지 입력한다.

```text
날짜 / 시간 / 구분 / 대상자 / 장소 / 참여 인원
1. 10월 12일(월) / 오전 11시 / 줌 미팅 / 신예영 / 온라인 / 전원
2. 10월 15일(목) / 오후 1시 / 릴스 촬영 / 김선아 / 오산 / 이지선, 윤지혜
```

- 연도 없는 날짜는 선택한 달력의 연도를 기본값으로 사용한다. 적용 연도는 입력창에서 변경할 수 있다. 연도에 맞지 않는 요일은 미리보기에서 날짜를 수정하거나 확인해야 등록된다.
- 단일 시간은 기본 1시간이며, `오전 9시~12시`는 3시간으로 해석한다. `오후 2시~5~6시`는 종료시간이 모호하므로 17:00/18:00 중 선택하거나 소요시간을 직접 지정해야 한다. `시간 미정`은 그대로 미정으로 표시한다. DB의 정렬용 기본 시간값을 확정된 시작시간처럼 표시하지 않는다.
- `줌 미팅`은 기본 종류인 강사 줌미팅에 연결한다. 릴스 촬영·광고 촬영 등 없는 종류는 관리자가 **새 구분 추가**에 동의하면 일정과 함께 추가한다. 일반 사용자는 기존 종류를 선택하거나 관리자에게 추가를 요청해야 한다.
- 대상자는 제목과 메모에 반영한다. 참여 인원의 `전원`은 현재 활성 사용자 전체를 선택한다. 쉼표로 구분한 이름은 활성 사용자와 매칭하며, 미등록 이름·동명이인은 직접 참여자를 선택하고 확정해야 한다. 참여자 없이도 등록할 수 있다.
- 장소의 온라인/장소 미정은 기본 옵션으로, 오산·강남·수서 등 다른 값은 직접 입력 장소로 변환한다. 미리보기에서 제목·날짜·시간·장소·종류·참여자를 변경하거나 행을 제외할 수 있다.
- 일괄 저장은 하나의 DB 트랜잭션으로 처리한다. 한 행이라도 실패하면 일정과 새 회의 종류 모두 롤백한다. 처리 후 응답이 유실된 경우 같은 창에서 다시 등록하면 동일 요청 ID로 결과를 조회하여 중복 생성을 막는다.

## 데이터와 권한

`shared_calendar_meeting_types`, `shared_calendar_events` 테이블 및 `calendar_private` 권한/검증 함수. RLS는 실제 Auth 계정의 비활성/차단 상태와 워크스페이스 구성원·관리자 역할을 확인한다. 회의 종류 추가만 관리자에게 허용하며 기본 종류의 식별 코드를 사용자 정의 항목으로 위조할 수 없다. 일정의 시간 간격과 범위, 강의/종류/워크스페이스 연결은 DB에서도 검증한다.

마이그레이션: `supabase/migrations/20261008090358_shared_calendar.sql`.

참여자 확장: `supabase/migrations/20261008100344_shared_calendar_participants.sql`. `participant_ids uuid[]`의 기본값은 빈 배열이고 일정/버전과 원자적으로 저장한다. 새 선택은 비공개 트리거에서 같은 워크스페이스의 활성·인증 계정인지 검증한다. 중복·NULL·다차원 배열·500명 초과 선택을 거부한다. 이후 탈퇴/삭제/비활성화된 기존 참여자는 이력으로 유지할 수 있으며 제거 후 다시 추가할 수는 없다. 이전 버전의 열린 클라이언트가 참여자 필드를 생략하면 기존 선택을 보존한다. 트리거는 고정 search_path를 사용하고 API 역할의 직접 실행을 금지한다.

장소·일괄 입력 확장: `supabase/migrations/20261008102522_shared_calendar_location_bulk_import.sql`. 장소 종류/텍스트와 `time_tbd`를 추가한다. 이전 버전의 열린 클라이언트가 새 필드를 생략하면 기존 값을 보존한다. `shared_calendar_imports`의 워크스페이스/요청 ID 키와 트랜잭션 잠금으로 재시도·동시 요청을 보호한다. `shared_calendar_import` RPC는 SECURITY INVOKER로 호출자 RLS와 관리자 권한을 적용하며 익명 실행을 금지한다. 서비스 키로 일괄 등록 권한을 우회하지 않는다.
