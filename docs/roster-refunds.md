# 수강생 환불자 관리

수강생 명단에서 이름을 눌러 정보 수정 창을 연 뒤 **환불신청하기**를 누릅니다. 이름, 전화번호, 이메일 주소, 강의명, 결제금액, 환불율, 날짜를 입력하고 환불 신청 사유를 선택한 뒤 **PDF 저장** 또는 **출력**을 선택합니다. 기존 정보는 자동 입력되며 수정할 수 있습니다. 날짜는 한국 시간 기준 오늘로 채웁니다. 환불율은 0~100%, 소수점 둘째 자리까지, 결제금액은 원 단위 정수로 입력합니다.

PDF는 브라우저에서 생성되어 다운로드됩니다. 한글 글꼴을 포함하며, 출력도 같은 PDF를 사용합니다. 출력 창이 차단되면 팝업 허용 안내를 표시합니다. PDF 뷰어가 자동 인쇄를 지원하지 않으면 뷰어의 인쇄 버튼을 사용합니다. PDF 작성 내용은 서버에 저장하거나 기존 수강생 정보에 반영하지 않습니다.

PDF 저장·출력만으로는 명단 상태가 바뀌지 않습니다. 같은 화면 하단의 **환불자로 변경**을 누르면 기존 환불 처리와 동일하게 환불자 명단으로 옮깁니다. PDF 필수 항목 입력 여부와 무관하게 사용할 수 있으며, 결제 시스템에서 실제 환불을 실행하지는 않습니다. PDF가 필요하면 명단 변경 전에 저장하세요.

PDF는 제공된 원본 환불 신청서의 크기(Letter, 612×792pt), 표, 약정 조항, 서명란을 유지합니다. 환불금액은 결제금액 × 환불율로 계산하고 원 미만은 버립니다. 날짜에는 요일도 자동으로 표시합니다. 환불 신청 사유는 A~D 중 하나를 선택하며 선택한 문자가 `3. 환불 신청 사유 ( B )`처럼 제목 괄호 안에 들어갑니다. D(기타 사유)를 선택하면 상세 사유를 입력해야 하며, PDF의 D 항목 옆에 표시합니다. 신청자 서명란에는 입력한 이름의 글자 사이를 두 칸씩 띄우고 `   (인)`을 붙입니다(예: `홍  길  동   (인)`). 긴 입력값은 칸 안에서 줄바꿈하고 글자 크기를 조절하며, 읽을 수 있는 크기로 담을 수 없으면 수정 안내를 표시합니다.

서비스에는 샘플의 개인정보, 금액, 날짜, 사유 선택, 원본 링크·메타데이터를 제거한 `public/templates/refund-application-v1.pdf`만 사용합니다. 개인정보가 들어 있는 원본은 로컬에 보관하며 공개 저장소에 포함하지 않습니다. 양식을 다시 준비하려면 PyMuPDF를 설치한 환경에서 `python scripts/prepare-refund-template.py "<원본 PDF 경로>"`를 실행합니다. 생성된 양식은 저장소에 포함되므로 서비스 실행·빌드에는 Python이 필요하지 않습니다.

환불 처리된 행은 일반 명단에서 빠지고 명단 바로 아래의 **환불자 명단 (조회 전용)**에 표시됩니다. 통합 수강생 명단에서도 동일하게 명단 아래에서 조회할 수 있습니다. 이름·전화번호·이메일로 검색하고 환불 표시일과 기존 비고를 확인할 수 있습니다.

- 환불 여부는 해당 명단의 수강 내역에 저장합니다. 다른 명단의 정상 수강 내역은 유지합니다.
- 환불자는 명단 비교, 중복 검사, 일반 명단 다운로드와 메시지 발송 대상에서 제외합니다.
- 결제자 비교에서는 환불 기록만 있는 연락처를 결제자 누락으로 집계하지 않습니다. 같은 비교 기준으로 정상 수강 내역도 있으면 정상 내역을 비교합니다.
- 명단 갱신 시 환불 기록을 보존하고, 환불 기록과 같은 전화번호의 업로드 행은 비교에서 제외합니다.
- 환불자는 수정·선택 삭제할 수 없습니다. 환불 상태와 처리 시각은 기존 명단 데이터에 저장되므로 추가 마이그레이션이 필요하지 않습니다.
