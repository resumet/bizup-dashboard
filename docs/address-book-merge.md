# 주소록 병합

- **목록 합치기**: 주소록 2~3개를 선택해 중복 전화번호를 정리한 새 주소록을 만듭니다.
- **유료 수강생 제외하기**: 주소록 1~3개를 합친 후, 별도로 선택한 명단 1개와 같은 전화번호를 제외합니다.
- 제외 명단은 각 강의의 **수강생관리 및 정산 → 유료수강생** 탭에 저장된 목록만 표시합니다. 강의명·강사·기수·무료강의 일시로 구분하며, 일반 수강생 매니저 명단과 주소록은 제외 대상으로 선택할 수 없습니다.
- 서버도 강의 연결, 유료 명단 여부, 강의와 명단의 워크스페이스 권한을 다시 확인합니다. 저장된 명단이 없으면 먼저 저장하라는 안내를 표시합니다.
- 수강생 명단은 저장된 최신 버전을 사용하고 환불자는 제외 대상에서 빠집니다. 결제자와 실제 수강생이 다르면 실제 수강생의 전화번호를 비교합니다.
- 전화번호의 하이픈·공백·한국 국가번호 표기를 정규화하여 비교합니다. 이름이나 이메일만 같은 사람은 제외하지 않습니다.
- 콜세일즈용 옵션은 기존처럼 010 외 번호를 먼저 제외합니다. 이후 중복을 정리하고 선택 명단과 비교합니다. 결과 창의 명단 제외 인원은 중복 없는 인원 수입니다.
- 원본 명단은 수정하지 않습니다. 모두 제외되면 빈 주소록을 생성하고 결과 창에 안내합니다.
- 서버에서 선택 개수, 중복 선택, 로그인 및 모든 명단의 워크스페이스 권한을 확인합니다. DB 스키마 변경은 없습니다.

검증:

```powershell
node node_modules/tsx/dist/cli.mjs --conditions=react-server --test src/lib/address-books/merge.test.ts
$env:PLAYWRIGHT_PACKAGE_PATH=(Resolve-Path '.cache/course-order-browser/node_modules/playwright').Path

```

통합 검증은 실제 API·페이지 컴포넌트와 메모리 DB 어댑터를 사용하며 운영 데이터는 변경하지 않습니다.
