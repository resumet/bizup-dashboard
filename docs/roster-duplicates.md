# 수강생 명단 중복 검사

홈의 **간편 도구 → 수강생 명단 중복 검사**에서 명단을 하나 이상 선택하고 **중복 검사하기**를 누릅니다. 분석 완료된 각 명단의 최신 저장본을 검사합니다.

- 기본 기준은 전화번호이며 이메일도 선택할 수 있습니다. 전화번호의 구분 기호·한국 국가번호, 이메일의 공백·대소문자를 정리합니다.
- 선택한 명단 안과 여러 명단 사이에서 같은 기준 값이 2행 이상 나오면 중복으로 표시합니다. 이름만 같다고 중복으로 판단하지 않습니다.
- 중복된 사람, 등장 횟수, 명단과 원본 행을 확인하고 전체 중복 결과를 CSV로 내려받을 수 있습니다.
- 추가 중복 행은 각 사람의 첫 행을 제외한 행 수입니다. 기준 값이 없거나 잘못된 행은 인원 집계에서 제외하고 별도로 보여줍니다.

최대 100개 명단·합산 100,000행까지 지원합니다. 로그인 사용자가 조회 가능한 명단만 검사하며 원본 데이터를 수정하거나 삭제하지 않습니다. 추가 마이그레이션은 필요하지 않습니다.
