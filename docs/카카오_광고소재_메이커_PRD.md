# 플러스친구 홍보소재 생성기 PRD

> 버전: v3.0  
> 작성일: 2026-08-30  
> 제품 형태: 개인용 비공개 웹서비스  
> 가칭: **플친소재 메이커**

---

## 1. 제품 정의

### 1.1 한 줄 정의

강의명, 강사명, 강의시간, 진행 상태, 특징 5가지, 핵심 타깃, 강사 이력과 사진을 입력하면 **서로 다른 설득 전략의 카카오 플러스친구 홍보소재 5개**를 자동 생성하고 수정·다운로드하는 개인용 웹서비스다.

### 1.2 목적

무료특강과 라이브 강의를 홍보할 때 반복되는 카피 기획, 이미지 배치, 진행 상태 변경 작업을 줄인다. 사용자는 정해진 정보만 입력하고 바로 발송 가능한 이미지와 메시지 문구 5세트를 얻는다.

### 1.3 핵심 결과물

한 번의 생성 작업으로 다음을 제공한다.

- 서로 다른 전략과 레이아웃의 홍보 이미지 5장
- 이미지별 메시지 제목 1개
- 이미지별 메시지 본문 1개
- 이미지별 CTA 버튼 문구 1개
- 카카오 모바일 메시지 미리보기
- PNG/JPG 및 문구 파일 다운로드

---

## 2. 범위

### 2.1 포함

- 개인 사용자 1명을 위한 비공개 웹서비스
- 강의·강사 정보 입력 및 저장
- 강사 사진, 책 표지, 증정품, 로고 및 참고 광고 이미지 업로드
- OpenAI API를 이용한 참고 이미지 분석과 광고 카피 생성
- AI 카피 5세트 생성
- 템플릿 기반 홍보 이미지 5장 생성
- 텍스트·사진·색상 간편 편집
- 메시지 본문 편집·복사
- 개별/일괄 다운로드
- 과거 프로젝트 불러오기·복제

### 2.2 제외

- 회원가입과 다중 사용자
- 수익모델, 구독, 결제, 요금제
- 팀 협업과 승인
- 카카오채널 직접 발송
- 광고 성과 추적
- 템플릿 마켓
- 전문 디자인 프로그램 수준의 자유 편집

## 3. 핵심 사용자와 요구

사용자는 온라인 무료강의, 라이브 방송, 유료강의 모집을 위해 카카오 플러스친구 메시지를 반복 제작하는 운영자 1명이다.

핵심 요구:

- 강의 정보를 한 번만 입력한다.
- 동일한 강의를 서로 다른 후킹으로 홍보한다.
- `잠시 후 시작`, `지금 진행 중` 같은 상태를 빠르게 반영한다.
- 강사 사진과 이력이 돋보이는 전문적인 결과물을 만든다.
- 생성된 카피와 디자인을 직접 수정한다.
- 결과물을 즉시 카카오 메시지 발송에 사용한다.

---

## 4. 사용자 흐름

1. 대시보드에서 `새 홍보소재 만들기`를 선택한다.
2. 강의 및 강사 정보를 입력한다.
3. 강사 사진과 관련 이미지를 업로드한다.
4. 강의 진행 상태를 선택한다.
5. `홍보소재 5개 만들기`를 실행한다.
6. AI가 서로 다른 전략의 카피 5세트를 만든다.
7. 템플릿 엔진이 카피와 이미지를 자동 배치한다.
8. 결과 5개를 한 화면에서 비교한다.
9. 원하는 소재의 문구, 사진, 색상을 수정한다.
10. 카카오 메시지 미리보기를 확인한다.
11. 이미지와 메시지 문구를 다운로드 또는 복사한다.
12. 프로젝트를 저장·복제해 다음 발송에 재사용한다.

### 5.3 참고 이미지 설정

사용자는 기존 플러스친구 광고, 유튜브 썸네일, 강의 홍보 이미지 등을 참고자료로 등록할 수 있다. 참고 이미지는 그대로 복제하지 않고 디자인 특징을 분석하는 용도로만 사용한다.

이미지별 설정:

- 참고 이미지 사용 여부
- 참고 목적: 전체 분위기, 색감, 레이아웃, 타이포그래피, 인물 배치, 혜택 표현, 긴급성 표현
- 중요도: 낮음, 보통, 높음
- 메모: `검은 배경과 노란 숫자만 참고`, `3분할 사진 구도 참고` 등
- 특정 소재에만 적용 또는 5개 전체에 적용

OpenAI가 이미지에서 추출할 항목:

- 배경색과 강조색
- 제목의 위치, 크기, 줄 수
- 인물·상품·성과 화면의 배치
- 상태 배지와 CTA 형태
- 숫자, 혜택 목록, 증정품의 표현 방식
- 전체 분위기와 정보 밀도
- 참고하면 안 되는 고유 로고, 인물, 문구, 브랜드 요소

분석 결과는 편집 가능한 `style_profile` JSON으로 저장한다. 사용자는 분석 결과에서 원하는 항목만 선택해 소재 생성에 반영할 수 있다.

### 5.4 진행 상태

| 상태 | 표현 방향 | CTA 예시 |
|---|---|---|
| 모집 중 | 날짜·시간과 핵심 혜택 | 무료강의 신청하기 |
| 하루 전 | 내일 진행·놓칠 혜택 | 참여 준비하기 |
| 당일 예정 | 오늘 진행·시간 강조 | 오늘 강의 신청하기 |
| 잠시 후 시작 | 시작 임박·즉시 행동 | 강의장 입장하기 |
| 지금 진행 중 | LIVE·현재 진행 강조 | 지금 바로 입장하기 |
| 마감 임박 | 마감 시간·사라지는 혜택 | 마감 전 신청하기 |

## 6. 자동 생성되는 5개 소재

5개 결과는 색상만 바꾼 복사본이 아니라 **서로 다른 설득 전략, 카피, 레이아웃**을 사용한다.

### 6.1 문제·불안 자극형

- 타깃의 문제를 질문이나 경고로 제시한다.
- 문제를 방치했을 때의 손실을 강조한다.
- 강의를 해결책으로 연결한다.
- 인물 사진과 큰 질문형 제목을 사용한다.

예: `광고를 멈추면 매출도 같이 멈추시나요?`

### 6.2 핵심 혜택·결과형

- 특징 5가지 중 가장 강한 결과를 메인으로 사용한다.
- 강의 후 얻게 되는 변화를 구체적으로 표현한다.
- 숫자와 결과를 시각적으로 강조한다.

예: `90분 만에 내 사업의 퍼널 구조를 완성하세요`

### 6.3 강사 신뢰·권위형

- 강사 사진을 크게 배치한다.
- 이력 중 가장 강한 2~3개를 강조한다.
- 실전 경험과 전문성을 중심으로 설득한다.

예: `100만 유튜브를 만든 11년 차 전문가의 실전 공개`

### 6.4 혜택·증정형

- 무료자료, 책, 체험권, 할인 등 추가 혜택을 크게 표현한다.
- 관련 이미지가 있으면 우선 배치한다.
- 증정품이 없으면 `강의 참여로 얻는 것`을 중심으로 바꾼다.

예: `지금 신청하면 가이드북 3권을 모두 드립니다`

### 6.5 긴급성·라이브형

- 현재 진행 상태를 가장 강하게 반영한다.
- `오늘`, `잠시 후`, `지금`, `마감`을 강조한다.
- CTA 대비를 높여 즉시 행동을 유도한다.

예: `지금 700명 이상 시청 중—바로 입장하세요`

참여 인원은 사용자가 실제 숫자를 입력했을 때만 사용한다.

## 7. 소재 한 세트의 구성

### 7.1 홍보 이미지

- 메인 후킹
- 보조 카피
- 강사명 또는 강사 이력
- 강의 일정 또는 진행 상태
- 특징·혜택 2~3개
- CTA 시각 요소
- 강사 사진, 책 표지, 증정품, 로고

### 7.2 메시지 제목

- 한 문장으로 핵심 행동을 유도한다.
- 이미지 메인 카피를 그대로 반복하지 않고 보완한다.

### 7.3 메시지 본문

- 첫 문장 후킹
- 강의에서 얻는 핵심 내용
- 특징 또는 혜택 2~3개
- 날짜·시간 또는 진행 상태
- 행동 유도 문장

### 7.4 CTA

- 진행 상태에 맞는 동사형 문구
- 짧고 즉시 이해되는 표현

## 8. 이미지 규격과 템플릿

### 8.1 기본 출력

카카오 운영 규격은 코드의 상수가 아니라 설정값으로 관리한다.

- 기본형: 800×800px
- 세로 강조형: 800×1,000px
- 고해상도: 2배 렌더링 옵션
- 출력: PNG, JPG

### 8.2 초기 템플릿 15개

- 문제·불안 자극형 3개
- 핵심 혜택·결과형 3개
- 강사 신뢰·권위형 3개
- 혜택·증정형 3개
- 긴급성·라이브형 3개

생성 시 각 전략에서 입력 정보에 가장 적합한 템플릿 1개를 선택한다.

### 8.3 템플릿 슬롯

- main_hook
- sub_copy
- instructor_name
- instructor_history
- feature_list
- event_date
- event_time
- status_badge
- benefit_badge
- participant_count
- cta_text
- instructor_image
- product_images
- gift_images
- logo

## 9. 기능 요구사항

### FR-01 프로젝트 대시보드

- 저장된 프로젝트 목록
- 썸네일, 강의명, 강사명, 진행 상태, 수정일 표시
- 프로젝트 열기, 복제, 이름 변경, 삭제
- 최근 수정 순 정렬
- `새 홍보소재 만들기` 버튼

### FR-02 정보 입력

- 특징 5개를 각각 입력하는 고정 필드
- 강사 이력을 항목별 추가·삭제·순서 변경
- 진행 상태 선택
- 필수값 검증과 예시 제공
- 기존 프로젝트 수정

### FR-03 이미지 업로드

- JPG, PNG, WebP 지원
- 업로드 즉시 미리보기
- 크롭, 회전, 삭제, 대표 사진 지정
- 사진별 용도 지정
- 선택적 배경 제거
- 이미지가 없어도 생성 가능
- 참고 광고 이미지 최대 10장 등록
- 참고 이미지별 목적, 중요도, 메모 지정
- 참고 이미지 삭제·교체·적용 대상 변경

### FR-04 참고 이미지 분석

- OpenAI Responses API에 참고 이미지와 분석 지시문을 전달한다.
- 여러 참고 이미지를 한 번의 프로젝트 분석 단위로 처리한다.
- 이미지별 분석 결과와 공통 스타일 프로필을 구조화 JSON으로 반환한다.
- 사용자는 색감, 레이아웃, 타이포그래피, 인물 배치 등 반영 항목을 선택한다.
- 참고 이미지의 문구·로고·인물·고유 그래픽을 그대로 복제하지 않는다.
- 분석 실패 시 해당 이미지만 제외하고 재시도할 수 있다.
- 같은 이미지의 분석 결과는 해시 기준으로 재사용해 불필요한 API 호출을 줄인다.

### FR-05 OpenAI 카피 생성

- 5개 전략별 카피 세트 생성
- 각 세트에 메인 후킹, 보조 카피, 이미지 내 특징, 제목, 본문, CTA 포함
- 지정된 JSON 구조로 출력
- 입력하지 않은 이력, 숫자, 성과, 혜택 생성 금지
- 문구별 직접 수정·개별 재생성
- `더 강하게`, `더 신뢰감 있게`, `더 짧게` 재작성
- OpenAI Responses API를 사용한다.
- Structured Outputs 방식의 JSON Schema로 결과 구조를 강제한다.
- 모델명은 코드에 고정하지 않고 환경변수로 설정한다.
- 프롬프트 버전과 실제 사용 모델명을 생성 기록에 저장한다.

### FR-06 이미지 5종 생성

- 전략별로 다른 템플릿 선택
- 카피와 사진 자동 배치
- 텍스트 길이에 따라 폰트와 줄바꿈 자동 조정
- 한글은 실제 텍스트 레이어로 렌더링
- 5개 결과를 한 화면에서 비교
- 각 소재에 전략 이름 표시
- 참고 이미지의 선택된 스타일 특성을 템플릿 추천과 배치 규칙에 반영
- 최종 한글과 사진 합성은 OpenAI 이미지 생성 결과가 아니라 자체 캔버스 엔진으로 처리

### FR-08 진행 상태 일괄 변경

- 프로젝트 상단에서 상태 변경
- 날짜·시간, 상태 배지, 긴급성 카피, CTA를 5개 소재에 반영

- `전체 반영` 또는 `선택 반영` 제공

- 긴 본문·짧은 본문 전환

- 제목, 본문, CTA 개별 복사
- 전체 메시지 한 번에 복사

### FR-10 다운로드

## 10. AI 생성 규칙

### 10.1 사실성

- 입력된 사실만 사용한다.
- 이력과 성과를 임의로 부풀리지 않는다.
- 참여 인원이 없으면 인원 관련 표현을 만들지 않는다.
- 무료 여부가 없으면 `무료`라고 쓰지 않는다.
- 증정 혜택이 없으면 `무료 증정`을 만들지 않는다.

### 10.2 문장 규칙

- 메인 후킹은 모바일에서 2~3줄 이내로 읽히게 한다.
- 메인 후킹과 보조 카피의 내용을 중복하지 않는다.
- 특징 5개 중 전략에 맞는 2~3개만 이미지에 사용한다.
- 나머지 특징은 메시지 본문에 활용한다.
- CTA는 행동 동사로 끝낸다.

### 10.3 위험 표현

다음은 경고하거나 안전한 표현으로 변경한다.

- 보장되지 않은 수익
- `무조건`, `100% 성공`, `누구나 돈 번다`
- 허위 희소성·허위 마감
- 근거 없는 참가자 수·매출
- 강사 이력을 과장하는 최상급 표현

### 10.4 구조화 출력

```json
{
  "materials": [
    {
      "strategy": "problem",
      "mainHook": "광고를 멈추면 매출도 같이 멈추시나요?",
      "subCopy": "반복해서 고객을 모으는 퍼널 구조를 공개합니다",
      "selectedFeatures": ["...", "..."],
      "instructorProof": ["..."],
      "statusBadge": "무료특강 모집 중",
      "messageTitle": "...",
      "messageBody": "...",
      "cta": "무료강의 신청하기",
      "riskFlags": []
    }
  ]
}
```

`materials`에는 problem, benefit, authority, gift, urgency 전략이 각각 1개씩 있어야 한다.

## 13. OpenAI 연동 설계

### 13.1 사용 범위

OpenAI는 다음 두 작업에 사용한다.

1. 참고 이미지의 시각적 특징 분석
2. 강의 정보와 분석 결과를 바탕으로 광고 카피 5세트 생성

최종 이미지의 한글 렌더링, 강사 사진 합성, 요소 배치와 다운로드는 웹서비스 내부에서 처리한다. OpenAI 이미지 생성 기능은 MVP 필수 범위에 포함하지 않는다.

### 13.2 API 방식

- 서버에서 OpenAI 공식 SDK와 Responses API를 호출한다.
- 참고 이미지는 모델의 이미지 입력으로 전달한다.
- 이미지 분석 및 카피 생성 결과는 JSON Schema 기반 Structured Outputs로 받는다.
- 브라우저에서 OpenAI API를 직접 호출하지 않는다.
- API 키는 서버 환경변수 `OPENAI_API_KEY`로만 관리한다.
- 모델은 `OPENAI_VISION_MODEL`, `OPENAI_COPY_MODEL` 환경변수로 분리 설정한다.
- 특정 모델명을 PRD에 고정하지 않고 개발 시점에 이미지 입력과 구조화 출력을 지원하는 모델을 선택한다.

OpenAI는 Responses API에서 이미지 입력을 지원하고, 구조화된 출력 기능을 별도 제공한다. 구현 시 최신 공식 문서의 입력 형식과 지원 모델을 확인한다. 참고: [OpenAI Images and vision](https://developers.openai.com/api/docs/guides/images-vision)

### 13.3 호출 단계

#### 호출 A: 참고 이미지 분석

입력:

- 참고 이미지 최대 10장
- 이미지별 참고 목적과 메모
- 원하는 분위기
- 금지 문구와 필수 문구

출력:

- 이미지별 시각 분석
- 공통 스타일 프로필
- 전략별 추천 레이아웃
- 복제하면 안 되는 고유 요소

#### 호출 B: 카피 5세트 생성

입력:

- 강의·강사 정보
- 특징 5개
- 핵심 타깃
- 진행 상태
- 강사 이력과 혜택
- 사용자가 선택한 스타일 프로필

출력:

- problem, benefit, authority, gift, urgency 5세트
- 각 세트의 이미지 문구, 메시지 제목·본문, CTA
- 템플릿 선택 힌트와 강조할 사진 유형
- 위험 표현 점검 결과

### 13.4 오류와 재시도

- 인증 오류: 설정 화면에서 API 키 상태를 확인하도록 안내
- 속도 제한: 지수 백오프로 제한 횟수 재시도
- 서버 오류: 동일 요청 ID로 안전하게 재시도
- JSON 검증 실패: 출력 스키마를 유지해 1회 자동 재생성
- 이미지 분석 실패: 실패한 이미지만 제외하거나 다시 분석
- 부분 성공: 성공 결과를 보존하고 실패 단계만 재실행
- 사용자 화면에는 기술 오류 원문 대신 이해하기 쉬운 안내 표시

### 13.5 비용·호출 절감

- 동일 참고 이미지는 파일 해시와 분석 프롬프트 버전으로 캐시한다.
- 카피 한 문장 수정은 전체 5세트가 아닌 해당 항목만 재생성한다.
- 참고 이미지 분석과 카피 생성을 별도 호출로 분리한다.
- 개발 로그에는 토큰 사용량, 이미지 입력 수, 호출 시간, 성공 여부를 기록한다.
- 개인용이므로 월 사용량 경고값을 환경설정에서 지정할 수 있게 한다.

### 13.6 개인정보와 자산 처리

- 사용자가 업로드한 강사 사진과 참고 이미지가 OpenAI로 전송됨을 설정 화면에 명시한다.
- 분석에 필요하지 않은 원본 메타데이터는 제거한다.
- API 요청·응답에 신청자 개인정보를 포함하지 않는다.
- API 키와 전체 요청 본문을 클라이언트 로그에 남기지 않는다.
- 참고 이미지의 저작권과 사용 권한은 사용자가 확인한다.

## 14. 생성 처리

1. 입력값과 이미지 형식 검증
2. 프로젝트 스냅샷 저장
3. 참고 이미지가 있으면 OpenAI로 스타일 분석
4. 사용자가 적용할 스타일 특성 확인
5. OpenAI로 전략별 카피 5세트 생성
6. JSON Schema, 사실성, 금지 표현 검사
7. 스타일 프로필을 반영해 전략별 템플릿 선택
8. 사진 우선순위 결정
9. 템플릿 슬롯에 카피·이미지 배치
10. 텍스트 넘침 검사·글자 크기 조정
11. 자체 캔버스로 이미지 5장 렌더링
12. 제목·본문·CTA와 함께 저장

한 단계가 실패하면 전체가 아닌 실패 단계부터 재시도한다.

## 15. 디자인 생성 원칙

- AI 이미지 생성 모델로 한글 문자를 그리지 않는다.
- 강사·상품 이미지는 업로드 원본을 우선 사용한다.
- 배경과 장식만 생성 이미지나 사전 자산을 사용한다.
- 메인 후킹을 화면에서 가장 크게 표시한다.
- 얼굴 위에 텍스트를 겹치지 않는다.
- 인물 시선 방향을 고려해 텍스트 위치를 선택한다.
- 모바일 축소 화면에서도 일정, 상태, CTA가 읽혀야 한다.
- 5개 결과가 색상만 다른 형태가 되지 않게 레이아웃 다양성을 강제한다.
- 참고 이미지는 색감·구도·정보 계층을 참고하되 원문, 로고, 인물, 고유 그래픽을 복제하지 않는다.

## 19. 수용 기준

### 입력

- 필수 입력 완료 후에만 생성 버튼이 활성화된다.
- 특징은 정확히 5개 입력한다.
- 강사 이력은 추가·삭제·순서 변경이 가능하다.

### 카피

- 5개 전략이 각각 1세트 생성된다.
- 5개 메인 후킹이 실질적으로 달라야 한다.
- 입력하지 않은 수치, 성과, 이력, 혜택을 생성하지 않는다.
- 문구 하나만 개별 재생성할 수 있다.
- OpenAI 응답이 정의된 JSON Schema에 맞지 않으면 저장하지 않는다.

### 참고 이미지

- 참고 이미지별 목적·중요도·메모를 지정할 수 있다.
- 분석 결과에서 색상, 구도, 타이포그래피 등 적용 항목을 선택할 수 있다.
- 참고 이미지의 원문과 로고가 생성 소재에 그대로 복제되지 않는다.
- 동일 이미지의 분석 결과를 재사용할 수 있다.

### 이미지

- 결과가 정확히 5개 생성된다.
- 각 결과는 다른 전략과 레이아웃을 사용한다.
- 한글이 깨지지 않고 편집 가능한 텍스트로 존재한다.
- 텍스트가 캔버스 밖으로 넘어가지 않는다.
- 강사 얼굴이 핵심 문구에 가려지지 않는다.

### 편집·다운로드

- 카피, 일정, 상태, CTA를 직접 수정한다.
- 사진을 교체하고 위치·크기를 바꾼다.
- 새로고침 후 자동 저장 내용이 유지된다.
- PNG/JPG가 정상적으로 열리고 미리보기와 일치한다.
- 이미지별 문구를 복사할 수 있다.

## 20. 테스트 시나리오

### A. 모집 중 무료강의

- 날짜·시간 표시
- 무료강의·신청 중심 CTA
- 5개 전략 정상 생성

### B. 지금 진행 중

- 날짜보다 LIVE·현재 진행 우선
- CTA를 `지금 바로 입장하기`로 변경
- 인원 미입력 시 숫자를 만들지 않음

### C. 강사 사진 없음

- 배경·텍스트·아이콘 중심 템플릿 사용
- 권위형은 이력 타이포그래피 중심

### D. 강사 이력 부족

- 입력된 이력만 사용
- 권위형을 실전 강의 내용 중심으로 보완

### E. 증정 혜택 없음

- 허위 증정 표현 금지
- 증정형을 `강의 참여로 얻는 결과` 중심으로 전환

### F. 긴 특징 문장

- 이미지에는 요약 표현 사용
- 원문은 메시지 본문에서 활용
- 텍스트 넘침 없이 렌더링

### G. 참고 이미지 8장 입력

- 모든 이미지를 분석하고 공통 스타일 프로필 생성
- 이미지별 메모와 중요도 반영
- 5개 결과가 참고 스타일을 공유하면서도 전략별 레이아웃 유지

### H. OpenAI API 오류

- 기존 입력과 업로드 이미지를 잃지 않음
- 오류 단계만 재시도 가능
- API 키가 화면이나 로그에 노출되지 않음

## 22. 완료 정의

1. 강의명, 강사명, 날짜·시간, 진행 상태, 특징 5가지, 핵심 타깃, 강사 이력을 입력할 수 있다.
2. 사진을 선택적으로 업로드할 수 있다.
3. 한 번의 실행으로 서로 다른 전략의 홍보소재 5개가 생성된다.
4. 각 소재는 이미지, 메시지 제목, 본문, CTA를 포함한다.
5. 생성된 문구와 사진을 수정할 수 있다.
6. 이미지 5개를 PNG/JPG로 다운로드할 수 있다.
7. 프로젝트를 저장·재접속·복제할 수 있다.
8. 입력하지 않은 수치나 강사 이력을 임의로 만들지 않는다.
9. 참고 이미지를 OpenAI로 분석하고 사용자가 선택한 스타일 특성을 5개 결과에 반영한다.
10. OpenAI API 키가 브라우저에 노출되지 않는다.
