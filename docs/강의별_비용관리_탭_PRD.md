# 강의별 비용관리 탭 PRD

## 1. 문서 개요

- 문서명: 비즈업클래스 강의별 비용관리 탭
- 목적: 강의 하나에 투입된 모든 비용을 부담 주체별로 기록하고, 공급가액과 부가세 및 증빙 상태를 관리하며, 확정된 비용을 강의 정산서에 자동 반영한다.
- 대상 사용자: 비즈업클래스 운영자, 회계·정산 담당자, 강의 담당자
- 연동 대상: 강의 관리, 강사 관리, 정산서 작성·조회, 파일 저장소

## 2. 배경 및 문제

현재 정산서 작성 단계에서 비용을 다시 입력하면 다음 문제가 발생한다.

- 실제 지출 기록과 정산서 입력값이 달라질 수 있다.
- 같은 비용을 여러 번 입력하거나 누락할 수 있다.
- 비용별 담당자, 지급일, 증빙 자료를 일관되게 관리하기 어렵다.
- 공급가액과 부가세, 강사·회사 부담액을 수기로 계산해야 한다.
- 비용이 수정될 때 기존 정산서와 불일치할 수 있다.

비용의 원천 데이터는 강의별 `비용` 탭에서 한 번만 입력하고, 정산서는 해당 데이터를 불러와 표시하는 구조로 변경한다.

## 3. 목표

1. 각 강의에 귀속되는 비용을 하나의 화면에서 관리한다.
2. 비용을 강사부담, 회사부담, 회사·강사 공동부담으로 구분한다.
3. 사용자가 실제 정산금액(부가세 포함 총액)을 입력하면 공급가액과 부가세를 자동 분리한다.
4. 비용별 지급 정보와 증빙 상태를 관리한다.
5. 확정된 비용을 정산서에 자동 반영하고 정산서 내 비용 직접 입력 기능을 제거한다.
6. 과거 정산서의 기존 비용 데이터는 훼손하지 않고 조회할 수 있게 한다.

## 4. 범위

### 4.1 포함

- 강의 상세 화면 내 `비용` 탭
- 부담 주체별 비용 섹션 및 기본 비용 항목
- 비용 추가·수정·삭제·복제
- 공급가액·부가세 자동 계산
- 공동부담 비율 설정 및 부담액 계산
- 증빙 종류, 필요 여부, 파일 첨부
- 합계 및 증빙 미비 현황
- 정산서 자동 연동
- 기존 정산 비용 데이터의 읽기 전용 표시 및 마이그레이션
- 변경 이력과 권한 관리

### 4.2 제외

- 실제 계좌이체나 카드 결제 실행
- 세금계산서 자동 발행·국세청 연동
- 회계 프로그램 자동 전표 처리
- 강사에게 정산서 자동 발송

## 5. 핵심 용어 및 정책

| 용어 | 정의 |
|---|---|
| 정산금액 | 사용자가 입력하는 실제 지급·결제 총액. 기본적으로 부가세 포함 금액 |
| 공급가액 | 정산금액에서 부가세를 제외한 금액 |
| 부가세 | 과세 거래에 포함된 VAT |
| 부담 주체 | 강사, 회사, 회사·강사 공동 |
| 비용 상태 | 예정, 지급완료, 취소 |
| 증빙 완료 | 증빙이 불필요하거나, 필요한 증빙 파일이 1개 이상 첨부된 상태 |
| 정산 반영 | 비용이 정산서 계산 및 표시 대상에 포함되는 상태 |

### 5.1 금액 및 부가세 계산

- 금액 입력 라벨은 `정산금액(부가세 포함)`으로 표시한다.
- 기본 과세 유형은 `과세(10%)`이다.
- 과세 유형은 `과세(10%)`, `면세`, `영세율` 중 선택할 수 있다.
- 과세(10%) 계산:
  - 공급가액 = 정산금액 ÷ 1.1 후 원 단위 반올림
  - 부가세 = 정산금액 - 공급가액
- 면세·영세율 계산:
  - 공급가액 = 정산금액
  - 부가세 = 0원
- 저장 시 `정산금액 = 공급가액 + 부가세`를 검증한다.
- 원 단위 반올림으로 차이가 생기면 부가세에 차액을 반영한다.
- 금액은 0원 이상 정수로 저장하며 통화는 KRW로 고정한다.
- 취소 상태의 비용은 합계와 정산서에 포함하지 않는다.

예시: 정산금액 1,100,000원, 과세(10%) 입력 시 공급가액 1,000,000원, 부가세 100,000원으로 표시한다.

### 5.2 공동부담 계산

- 기본 부담률: 회사 50%, 강사 50%
- 비용 건별로 회사·강사 부담률을 변경할 수 있다.
- 두 부담률의 합은 반드시 100%여야 한다.
- 회사 부담액 = 정산금액 × 회사 부담률 후 원 단위 반올림
- 강사 부담액 = 정산금액 - 회사 부담액
- 공급가액과 부가세도 같은 비율로 나누며, 반올림 차액은 강사 부담분에 반영한다.
- 정산서에서 강사 차감 비용으로 반영되는 금액은 `강사 부담액`이다.

## 6. 정보 구조 및 화면

### 6.1 진입 경로

`강의 관리 > 강의 선택 > 비용 탭`

상단에는 강의명, 강사명, 강의 기간, 정산 상태를 표시한다.

### 6.2 요약 영역

다음 카드를 표시한다.

- 총비용: 취소를 제외한 전체 정산금액
- 강사 부담 합계
- 회사 부담 합계
- 공급가액 합계
- 부가세 합계
- 증빙 미비: 증빙이 필요하지만 파일이 없는 비용 건수와 금액

### 6.3 비용 섹션 및 기본 항목

#### A. 회사부담항목

- 유튜브 출연료
- 교안 제작비
- 상세페이지 제작비
- 스튜디오 이용비용 (+PD)
- 광고집행비
- 오프라인 행사장 대여비

#### B. 강사부담항목

- 인스타그램 대행비

#### C. 회사·강사 공동부담항목

- 유튜브 출연 RS비용
- 구글 광고비
- 메타 광고비

각 기본 항목은 비용이 아직 없어도 빈 행으로 노출하거나 `비용 등록` 버튼을 제공한다. 같은 항목에 여러 번 지출할 수 있으므로 하나의 항목 아래 여러 비용 건 등록을 허용한다. 각 섹션에 `기타 비용 추가` 기능을 제공하며 부담 주체는 해당 섹션 값으로 자동 설정한다.

### 6.4 목록 컬럼

| 필드 | 유형 | 필수 | 규칙 |
|---|---|---:|---|
| 이름 | 텍스트/항목 선택 | Y | 기본 항목 선택 또는 직접 입력, 1~100자 |
| 담당자 | 사용자 선택/텍스트 | Y | 내부 사용자 선택을 우선하며 외부 담당자는 직접 입력 가능 |
| 정산금액 | 숫자 | Y | 0원 이상, 천 단위 구분 표시 |
| 공급가액 | 자동 계산 | Y | 읽기 전용 |
| 부가세 | 자동 계산 | Y | 읽기 전용 |
| 과세 유형 | 선택 | Y | 과세(10%), 면세, 영세율 |
| 지급연월일 | 날짜 | 조건부 | 지급완료 상태일 때 필수, YYYY-MM-DD |
| 비용 상태 | 선택 | Y | 예정, 지급완료, 취소 |
| 증빙필요 | 체크/토글 | Y | 기본값 `필요` |
| 증빙종류 | 다중 선택 | 조건부 | 세금계산서, 종이영수증, 이체기록, 카드영수증, 기타 |
| 증빙서류 | 파일 첨부 | 조건부 | 증빙필요가 `필요`이고 지급완료일 때 1개 이상 필요 |
| 비고 | 장문 텍스트 | N | 최대 1,000자 |
| 정산 반영 | 토글 | Y | 기본값 ON |

공동부담 섹션에는 다음 컬럼을 추가한다.

- 회사 부담률, 강사 부담률
- 회사 부담액, 강사 부담액

### 6.5 증빙 첨부

- 한 비용 건에 여러 파일을 첨부할 수 있다.
- 허용 형식: PDF, JPG, JPEG, PNG, XLS, XLSX
- 파일당 최대 용량: 20MB
- 파일별 원본 파일명, 업로드 사용자, 업로드 일시를 기록한다.
- 파일 미리보기 또는 다운로드를 제공한다.
- `증빙종류=기타` 선택 시 종류 설명을 필수 입력한다.
- 종이영수증은 스캔·촬영본 첨부를 허용한다.

## 7. 사용자 흐름

### 7.1 비용 등록

1. 사용자가 강의 상세의 `비용` 탭에 진입한다.
2. 부담 섹션과 비용 항목을 선택한다.
3. 담당자, 정산금액, 과세 유형, 비용 상태를 입력한다.
4. 시스템이 공급가액과 부가세를 즉시 계산해 보여준다.
5. 공동부담 비용이면 부담률과 양측 부담액을 보여준다.
6. 지급완료인 경우 지급연월일과 필요한 증빙을 입력한다.
7. 저장 후 섹션 합계와 상단 요약을 갱신한다.

### 7.2 비용 수정·삭제

- 정산서 확정 전: 수정·삭제 가능
- 정산서 확정 후: 일반 사용자는 수정·삭제 불가, 관리자만 `정산 확정 취소` 후 변경 가능
- 삭제는 물리 삭제가 아닌 소프트 삭제로 처리하고 변경 이력에 남긴다.
- 이미 정산서에 불러온 비용이 변경되면 미확정 정산서는 즉시 재계산한다.

### 7.3 증빙 미비 관리

- `증빙필요=필요`, `비용 상태=지급완료`, 첨부 파일 없음이면 `증빙 미비` 배지를 표시한다.
- 증빙 미비 비용도 저장할 수 있으나 경고를 표시한다.
- 정산서 확정 시 증빙 미비 건이 있으면 건수를 안내하고 관리자 확인 후 확정하도록 한다.

## 8. 정산서 연동

### 8.1 원칙

- 비용 데이터의 단일 원천은 강의별 `비용` 탭이다.
- 정산서 작성 화면의 신규 비용 입력·수정·삭제 기능을 제거한다.
- 정산서에는 비용 탭에 저장된 데이터를 읽기 전용으로 표시한다.
- 정산 대상은 `취소가 아님`, `정산 반영=ON`, 해당 정산 기간의 기준일에 포함되는 비용이다.
- 비용 귀속 기준일은 기본적으로 지급연월일이며, 예정 비용은 정산서 확정 대상에서 제외한다.

### 8.2 정산서 반영 규칙

| 비용 구분 | 정산서 강사 정산금 계산 | 정산서 표시 |
|---|---|---|
| 강사부담 | 정산 예정액에서 정산금액 전액 차감 | 강사부담 비용에 표시 |
| 회사부담 | 강사 정산액에서 차감하지 않음 | 회사부담 비용에 참고 표시 |
| 공동부담 | 정산 예정액에서 강사 부담액만 차감 | 공동부담 총액·비율·양측 부담액 표시 |

- 정산서 비용 표에는 이름, 공급가액, 부가세, 정산금액, 부담 구분, 강사 부담액, 회사 부담액, 지급일, 증빙 상태를 표시한다.
- 비용 합계는 강사부담, 회사부담, 공동부담으로 각각 구분한다.
- 최종 강사 지급액 산식은 기존 매출·수수료·RS 정책을 유지하되, 비용 차감값만 비용 탭에서 가져온다.
- 정산서 생성 시 반영된 비용 ID와 당시 금액·비율의 스냅샷을 저장한다.
- 정산서 확정 이후 비용 원본이 바뀌어도 확정본 스냅샷은 자동 변경하지 않는다.
- 확정 취소 후 재생성할 때 최신 비용 데이터를 다시 불러온다.

### 8.3 기존 비용 입력 영역 변경

- 기존 정산서 작성 화면에서 사용자가 비용을 직접 입력하던 UI를 삭제한다.
- 같은 위치에 `비용 관리에서 불러온 내역`을 읽기 전용으로 표시한다.
- `비용 관리로 이동` 버튼을 제공하고 현재 강의의 비용 탭으로 연결한다.
- 비용이 없을 때는 `등록된 비용이 없습니다. 비용 관리에서 먼저 등록해 주세요.`를 표시한다.

## 9. 기존 데이터 전환

1. 기존 정산서에 저장된 비용은 삭제하지 않는다.
2. 마이그레이션 시 기존 비용 건을 해당 강의의 비용 탭으로 복사하고 `기존 정산서 이관` 표시를 남긴다.
3. 기존 데이터에 부담 주체가 없으면 기본값을 자동 확정하지 않고 `분류 필요` 상태로 둔다.
4. 금액만 있는 기존 데이터는 과세 유형을 `확인 필요`로 두고 관리자 검토를 요구한다.
5. 이미 확정된 과거 정산서는 기존 스냅샷을 그대로 조회한다.
6. 이관 완료 후 신규 정산서는 비용 탭 데이터만 사용한다.
7. 중복 이관을 방지하기 위해 기존 비용 레코드 ID와 신규 비용 ID의 매핑을 저장한다.

## 12. 유효성 검증 및 오류 처리

- 정산금액, 이름, 담당자, 과세 유형, 비용 상태는 필수다.
- 지급완료 상태에서는 지급연월일이 필수다.
- 공동부담률 합계가 100%가 아니면 저장할 수 없다.
- 강사부담은 강사 100%, 회사부담은 회사 100%로 고정한다.
- 과세 유형 변경 시 공급가액과 부가세를 즉시 재계산하고 확인 메시지를 표시한다.
- 첨부 실패 시 비용 입력 내용은 유지하고 재시도 기능을 제공한다.
- 정산 확정 중 비용이 변경되면 최신 버전 확인 후 충돌 메시지를 표시한다.
- 음수 금액은 허용하지 않는다. 환입·환불은 별도 마이너스 입력 대신 원비용 취소 및 조정 비용 정책으로 처리한다.

## 13. 검색·필터·다운로드

- 검색: 비용명, 담당자, 비고
- 필터: 부담 주체, 비용 상태, 지급 기간, 증빙 미비, 과세 유형, 정산 반영 여부
- 정렬: 지급일, 등록일, 금액
- 엑셀 다운로드: 현재 필터 결과와 화면 합계를 포함
- 첨부 파일 일괄 다운로드는 후속 기능으로 둔다.

## 14. 비기능 요구사항

- 금액 계산은 프론트엔드 미리보기와 서버 저장 시 각각 수행하며 서버 계산값을 기준으로 한다.
- 목록 및 합계 조회 응답 목표는 일반적인 강의당 500건 이하에서 2초 이내다.
- 첨부 파일은 권한 확인 후 접근 가능한 비공개 저장소에 보관한다.
- 모든 생성·수정·삭제와 정산 확정 행위를 감사 로그로 남긴다.
- 날짜는 한국 시간(Asia/Seoul)을 기준으로 저장·표시한다.
- 동시에 수정할 경우 낙관적 잠금 또는 수정 버전 검사를 적용한다.

## 15. 주요 화면 상태

- 로딩: 행 스켈레톤 및 합계 영역 로딩 표시
- 빈 상태: 기본 항목과 `첫 비용 등록` 안내
- 저장 중: 중복 저장 방지
- 저장 완료: 토스트 메시지와 합계 즉시 갱신
- 증빙 미비: 행 경고 아이콘 및 상단 미비 건수 표시
- 정산 확정: 잠금 아이콘과 읽기 전용 상태
- 이관 데이터: `기존 정산서 이관`, `분류 필요`, `과세 확인 필요` 배지

## 16. 수용 기준

1. 강의마다 독립된 비용 탭과 세 개의 부담 섹션이 표시된다.
2. 지정된 10개 기본 비용 항목이 정확한 섹션에 노출된다.
3. 과세 정산금액 1,100,000원 입력 시 공급가액 1,000,000원, 부가세 100,000원이 표시·저장된다.
4. 면세 또는 영세율 선택 시 부가세가 0원으로 계산된다.
5. 공동부담 60:40 설정 시 회사·강사 부담액의 합이 정산금액과 일치한다.
6. 모든 비용에 요청된 필드와 복수 증빙 파일을 기록할 수 있다.
7. 지급완료 비용에 지급일이 없으면 저장이 차단된다.
8. 증빙이 필요한 지급완료 비용에 파일이 없으면 증빙 미비로 집계된다.
9. 정산서에서 비용 직접 입력이 불가능하고 비용 탭의 내역이 읽기 전용으로 표시된다.
10. 강사부담 전액과 공동부담 중 강사 부담액만 강사 정산금에서 차감된다.
11. 회사부담 비용은 강사 정산금에서 차감되지 않는다.
12. 확정 정산서에는 비용 스냅샷이 남아 이후 원본 수정의 영향을 받지 않는다.
13. 기존 확정 정산서의 비용 기록은 그대로 조회할 수 있다.
14. 비용 변경 이력을 사용자와 시각을 포함해 조회할 수 있다.

## 18. 개발 전 확정 필요 정책

아래 값은 본 PRD에서 구현 가능한 기본안으로 정의했으나 운영 정책 확정이 필요하다.

1. 인스타그램 대행비를 회사부담으로 분류하는 것이 맞는지
2. 공동부담의 기본 비율을 50:50으로 적용할지
3. 정산금액이 항상 부가세 포함 총액인지, 공급가액 입력 방식도 허용할지
4. 증빙 미비 상태에서 정산서 확정을 허용할지
5. 비용의 정산 귀속일을 지급일로 확정할지
6. 강사에게 회사부담 비용과 증빙 상태까지 공개할지
7. 환불·환입 비용을 조정 비용으로 처리할 구체적인 운영 방식

## 19. 권장 테스트 케이스

- 과세·면세·영세율별 금액 계산과 원 단위 반올림
- 1원, 10원, 매우 큰 금액 입력
- 공동부담 50:50, 60:40, 0:100, 100:0
- 한 항목의 복수 비용 등록
- 증빙 다중 첨부, 실패, 삭제, 기타 유형 입력
- 예정→지급완료→취소 상태 변경
- 정산 기간 경계일과 한국 시간 처리
- 미확정 정산서의 비용 자동 갱신
- 확정 정산서의 스냅샷 불변성
- 기존 비용 마이그레이션 재실행 시 중복 방지
- 동시 수정 충돌과 권한 없는 수정 차단
