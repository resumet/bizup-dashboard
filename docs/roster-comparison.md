# 결제자·수강생 명단 비교

홈의 **간편 도구 → 결제자·수강생 명단 비교**에서 실행합니다.

1. 왼쪽에 결제자 `.xlsx` 또는 UTF-8 `.csv` 파일을 넣습니다. 엑셀은 첫 번째 시트를 읽으며 첫 20행 안의 이름(회원명·고객명), 전화번호(휴대전화번호·연락처), 이메일 열 제목을 인식합니다.
2. 오른쪽에서 분석 완료된 수강생 명단을 여러 개 선택합니다. 각 명단의 최신 저장본을 합산합니다.
3. 전화번호 또는 이메일을 비교 기준으로 선택한 뒤 **명단 비교하기**를 누릅니다.
4. **결제자에만 있는 사람**, **수강생에만 있는 사람**을 각각 확인하고 CSV로 내려받습니다. CSV에는 해당 결과 전체가 포함됩니다.

전화번호는 구분 기호와 한국 국가번호를 정리하고, 이메일은 앞뒤 공백과 영문 대소문자를 정리합니다. 같은 비교 기준 값은 한 사람으로 합칩니다. 이름만으로 동일인을 판단하지 않습니다. 기준 값이 없거나 잘못된 행은 별도의 확인 필요 목록에 표시합니다.

결제자 파일의 모든 데이터 행을 비교 대상으로 사용하므로 환불·취소 등 제외할 내역은 업로드 전에 정리해야 합니다. 파일은 최대 4MB·50,000행, 수강생 명단은 최대 100개·합산 100,000행을 지원합니다. 업로드와 결과는 데이터베이스에 저장하지 않으며 로그인 사용자가 조회 가능한 명단만 비교합니다. 추가 DB 마이그레이션은 필요하지 않습니다.
