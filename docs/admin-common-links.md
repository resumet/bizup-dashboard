# 관리자 화면과 공통 링크

최고관리자는 `/admin`에서 기존 사용자 권한과 `바로가기 → 공통` 링크를 관리한다. 기존 `/admin/users` 주소도 사용할 수 있다.

이름·HTTP(S) 주소를 입력하고 위/아래 버튼으로 순서를 변경한 뒤 `공통 링크 저장`을 누른다. 삭제도 저장 시 반영된다. 최대 50개이며 모두 삭제한 빈 명단도 저장할 수 있다. 일반 사용자는 로그인 후 링크 열기·복사만 가능하다.

링크 목록은 Supabase Storage의 비공개 `admin-settings` 버킷에 `common-links.json`으로 저장한다. 서버의 기존 service role 키만 사용하고, 버킷은 첫 저장 시 생성한다. DB 마이그레이션이나 추가 환경변수는 필요 없다. 별도의 공개 접근 정책을 추가하지 않는다.

저장 전에는 기존 3개 링크를 기본값으로 제공한다. 저장소 조회 실패는 기본값으로 덮지 않고 오류로 표시한다. 메뉴를 다시 열 때 서버에서 최신 목록을 가져온다.
